# 实验能力与适用边界

| 功能 | 当前实现 | 使用要求 |
| --- | --- | --- |
| 对比模型 | DEHCD-S/M/L 与九种基线，四个数据集共 48 个主配置 | 所有模型使用同数据划分、监督信号、预算与选模规则 |
| 消融与容量对照 | HOG、DPM、GCBM/WASM、IRB 与独立 flow/gate 控制 | BiCSF 包括 GCBM 和 WASM；容量对照不表示感受野或 FLOPs 相等 |
| 训练策略 | 采样、类别权重、层级损失、定位辅助监督、BN、优化器的独立对照 | 按配置中的 reference 和 allowed_changes 检查控制变量 |
| 多随机种子 | 独立进程、快照、断点恢复、均值、样本标准差及配对统计 | 不混合不同代码、数据或参数条件；训练种子不是独立灾害事件 |
| 数值稳定性 | FP32 损失、梯度检测/裁剪、Haiti GN epsilon 与前景退化保护 | 短程有限梯度测试不能证明长期收敛或最优精度 |
| 数据独立性 | 样本 ID、文件路径与显式场景 group 的跨 split 检查 | 地理与事件独立性需要真实来源元数据 |
| 性能 | 参数统计、设备同步测速与 RTX 5090 运行参数 | 输入尺寸、精度、物理 batch 和累积次数必须一同记录 |

操作入口见 [训练协议](EXPERIMENT_PROTOCOL.md)、[受控比较](FAIR_COMPARISONS.md) 和 [运行参数](RUNTIME_PROFILE.md)。
